# DNS补充

## DNS的解析记录类型

- A记录：把域名解析为IPV4地址。

  ```tex
  example.com   IN   A   1.1.1.1
  ```

- AAAA记录：将域名转为IPv6地址。

  ```tex
  example.com   IN   AAAA  2001:0db8:85a3:0000:0000:8a2e:0370:7334
  ```

- CNAME记录：把一个域名解析为另外一个域名。

  ```tex
  example.com   IN   CNAME   www.example.com
  ```

## 各级解析及其优先级

- 用户通过浏览器访问某个域名

  - 解析过程：Chrome DNS缓存 -> HOSTS文件 -> 操作系统DNS缓存 -> DNS缓存服务器。

    注：HOSTS文件需要管理员权限才能编辑，其中存放的是A记录。

    ```tex
    # 不同操作系统下的HOSTS文件位置
    Linux：		/etc/hosts
    Windows：	C:\Windows\System32\drivers\etc\HOSTS
    ```

- 不通过浏览器访问某个域名
  - 解析过程：HOSTS文件 -> 操作系统DNS缓存 -> DNS缓存服务器。

# 跨局域网通信必备的四种地址

- 局域网内通讯所需地址：
  - IP地址
  - 子网掩码
- 跨局域网通信所需地址：
  - IP地址
  - 子网掩码
  - 网关的IP地址
- 通过域名访问所需地址：
  - IP地址
  - 子网掩码
  - 网关的IP地址
  - DNS解析服务器地址

- 补充：
  - 东西流量：服务器集群机器间的通信
  - 南北流量：局域网内部机器与外网之间的通信
- 地址的获取方式：
  - 动态获取：DHCP会自动从IP地址池中分配一个可用的IP地址给计算机。
  - 静态/永久配置：把IP地址信息写到网卡配置文件中。

# 网络程序的两种架构

- CS架构：Client - Server
- BS架构：Browser - Server

# BS架构网络通信过程（重点）

1. 打开浏览器，输入一个URL地址
2. 计算机会请求本地DNS，把域名解析为IP地址。
3. 应用层：用HTTP协议对数据包进行封装。
4. 传输层：用TCP协议对数据包进行封装。
5. 网络层：用IP协议对数据包进行封装。
6. 数据链路层：用以太网协议对数据包进行封装。

​	注意：以太网协议的数据部分，默认的最大传输单元（MTU）是1500字节，如果超过1500字节，则需要分片、多次发送。

# TCP协议、UDP协议

- TCP协议也被称之为可靠协议，但可靠不是因为面向连接，而是因为确认机制。只有在确认服务端收到数据请求后，才会释放掉内存中的数据。

- UDP协议也被称之为不可靠协议，面相无连接的一种协议，没有确认机制，所以并不可靠。相对于TCP协议而言，数据传输效率更高。

# 补充知识

## 子网划分

子网划分的核心，其实就是控制子网掩码的长短，来讲IP分配到不同的网段中。

## 虚拟局域网（VLAN）

- LAN：局域网
- VLAN：虚拟局域网，通过虚拟技术讲一个交换机分成多个广播域去用，一个广播域就是一个小的局域网。
