# day06 系统构成与shell核心

## 1. Linux系统构成

### 从功能纬度进行划分

- 第一部分：系统调用接口
- 第二部分：Linux内核

**应用程序本身是无法操控硬件的，但凡想操控硬件，都需要给系统发送请求。**

**操作系统的两种工作状态：**

- 用户态：运行的系统接口代码在于应用程序打交道
- 内核态：运行的是系统的内核代码在于硬件打交道

### 从文件纬度进行划分

- 第一部分：
  - bootfs（操作系统启动前）：包含操作系统启动文件（bootloader程序，不是以文件的形式存在，**是直接写入硬盘的第一个扇区/mbr**）、内核文件(/boot/vm...)
- 第二部分：
  - rootfs（操作系统启动后）：本质就是一堆文件。

## 2. Linux系统的启动顺序

- 第一步：通电，启动BIOS程序
- 第二步：BIOS根据配置信息，找到启动盘
- 第三步：BIOS读取启动盘第一块扇区MBR主引导记录（放着的是BOOTLOADER程序）放入内存，让CPU来执行，BOOTLOADER成功启动。
- 第四步：BOOTLOADER启动以后，负责从硬盘中找到内核文件读入内存，启动该部分文件。此时，操作系统就已经启动起来了。

​	操作系统启动以后，负责管理一系列进程（进程其实就是一堆运行起来的程序文件），这些进程可以分为两大类。

​	内核先启动一个父进程，PID为0，0号进程负责运行两个顶级程序，产生两个顶级的进程。

- 运行init程序，PID为1，该进程是所有用户态进程的父进程。
- 运行kthreadd程序，PID为2，该进程是所有内核态进程的父进程。

​	Linux系统的启动级别：

- init 0：关机
- init 6：重启
- init 3：进入字符终端（BASH环境）
- init 5：进入图形界面（需要提前安装好图形桌面，安装图形界面命令：yum -y group install "Server with GUI"）

## 3. shell解释器介绍

​	在默认启动级别为3的情况下，Linux系统启动之后默认会启动一个命令解释器，这个命令解释器会铺满整个屏幕（称之为字符终端），在这个终端中没有鼠标和图形化界面，只能在其中输入命令。

​	Linux系统中的命令解释器，被称之为shell，shell的中文意思是贝壳，表达了对系统接口封装的思想。

​	具体来说shell解释器分为很多种类，默认用的是bash这种。

## 4. shell交互式环境

​	[]内各个部分的意思：

- 第一部分：当前登录的用户名称（root）
- 第二部分：分隔符（@）
- 第三部分：当前登录的主机名称（10.0.25.113）
- 第四部分：当前所在的相对路径（~）

​	[]外各个部分的意思：

- $：表示当前登录的用户身份是一个普通用户
- #：表示当前登录的用户身份是一个超级管理员

​	补充：

- useradd 用户名
- passwd 用户名
- echo "123" | passwd --stdin egon # 为用户以非交互式的方式，添加密码

## 5. shell脚本

​	脚本其实就是一个简单的程序，整个程序就是一个文件。

​	把你执行某个任务需要的10条命令扔到一个文件中，该文件就是一个shell脚本。

## 6. shell命令的基本用法

```bash
# ls -l /boot
```

上面的命令由三部分组成：

- ls：命令，代表想要让计算机去做什么事情
- -l：选项，控制命令具体怎么做（可选部分）
- /boot：参数，命令具体操作的目标（可选部分）

```bash
# 以下是命令有哪些组合的方式：
# ls
# ls /boot
# ls -l
# ls -l /boot
```

# 7. bash解释器交互式环境的特性/快捷方式

```bash
## 快捷键
# Ctrl + C : 强制中断当前进程的运行
# Ctrl + L : 清空屏幕, 等同于执行clear命令

# Ctrl + E : 光标移动到命令的最末端
# ↑ : 在终端中搜索并显示上一条输入过的历史命令
# ↓ : 在终端中搜索并显示下一条输入过的历史命令
# Tab : 自动补全

## 命令
# history : 查出历史输入过的命令, 以及每条命令对应的编号
# history -c ：清空历史输入过的命令
# !$ : 取上一条命令的参数
```

## 8. shell命令的种类及优先级（从高到低）

1. 带着路径用命令（相对路径及绝对路径）

2. 别名：用alias命令创建的别名

3. 复合命令（Compound Commands）

   ```shell
   # for ((i=0;i<3;i++));do echo 11;done
   ```

4. Function定义命令/函数

   ```bash
   # f() { echo 11; }; f
   ```

5. bash解释器内置命令（内置在shell解释器中，解释器内部集成）

6. hash缓存机制（把输入过的历史命令缓存在内存中，在下次执行时可减少性能开销，提高运行效率）

7. 环境变量PATH（与命令的查找有关）
